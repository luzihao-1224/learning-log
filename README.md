# learning-log

从 0 到 AI Agent 工程师的学习日志。

## 这是什么
记录每天学什么、卡在哪、产出什么。公开记录是为了逼自己讲清楚 —— 讲不清就是没学会。

## 目录结构
- `log.csv`  每日学习记录（日期 / 阶段 / 今日目标 / 投入时长 / 产出 / 卡点 / 明天第一件事）
- `day1.py`  第一个练手脚本
- `AI-Agent-学习路线.md`（后续加入）
